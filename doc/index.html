Standard Lua Libraries

This is a collection of light-weight libraries for Lua 5.1 (including LuaJIT), 5.2 and 5.3 written in pure Lua, comprising:

  1. Enhanced and expanded versions of some core Lua functions in the std module itself;

  2. Enhanced versions of some core Lua libraries: std.debug, std.io, std.math, std.package, std.string and std.table;
