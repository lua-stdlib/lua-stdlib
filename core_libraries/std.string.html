Module std.string

Additions to the core string module.

The module table returned by std.string also contains all of the entries from the core string table. An hygienic way to import this module, then, is simply to override the core string locally:

local string = require 'std.string'

finds (s, pattern[, init=1[, plain]])
Repeatedly string.find until target string is exhausted.

Parameters:

  • s string target string
  • pattern string pattern to match in s

  • plain boolean inhibit magic characters (optional)

Returns:

    list of {from, to; capt={captures}}

See also:

Usage:

    for t in std.elems(finds('the target string', '%S+')) do
   print(tostring(t.capt))
end

pad (s, w[, p=' '])
Justify a string. When the string is longer than w, it is truncated(left or right according to the sign of w).

Parameters:

  • s string a string to justify
  • w integer

    width to justify to(-ve means right-justify; +ve means

    left-justify)
  • p string string to pad with (default ' ')

Returns:

    string s justified to w characters wide

Usage:

    print(pad(trim(outputstr, 78)) .. '\n')
pickle (x)
Convert a value to a string that loads as an equal value. Strings, numbers, booleans, nil and tables of those, with keys in a stable order. Tables that contain themselves, functions, userdata and threads raise an error.

Parameters:

  • x object to pickle

Returns:

    string reversible string rendering of x

See also:

    std.eval

Usage:

    function slow_identity(x)
   return std.eval(pickle(x))
end

render (x, vfns[, roots])
Turn tables into strings with recursion detection. With a table of rendering functions, this is the std.normalize string.render. The 41.2 form, with five callback functions in place of vfns, is deprecated.

Parameters:

  • x object to convert to string
  • vfns table

    table of virtual functions to control rendering,

    as for `std.normalize` `string.render`
  • roots table used internally for cycle detection (optional)

Returns:

    string representation of x

Usage:

    function printarray(x)
   return render(x, arrayvfns)
end

split (s[, sep='%s+'])
Split a string at a given separator. Separator is a Lua pattern, so you have to escape active characters, ^$()%.[]*+-? with a % prefix to match a literal character in s.

Parameters:

  • s string to split
  • sep string separator pattern (default '%s+')

Returns:

    list of strings

Usage:

    words = split 'a very short sentence'
tfind (s, pattern[, init=1[, plain]])
Do string.find, returning a table of captures.

Parameters:

  • init integer start position (default 1)
  • plain boolean inhibit magic characters (optional)

Returns:

  2. int end of match

See also:

Usage:
