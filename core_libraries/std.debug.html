Module std.debug

Additions to the core debug module.

The module table returned by std.debug also contains all of the entries from the core debug table. An hygienic way to import this module, then, is simply to override the core debug locally:

local debug = require 'std.debug'

Deprecation

DEPRECATED (version, name[, extramsg], fn)
Wrap a deprecated function to warn the first time it is called. Unless std._debug.deprecate is false, the warning goes to stderr; with std._debug.deprecate set to true, the deprecated function is not defined at all.

Parameters:

  • version string first deprecation release version
  • name string function name for automatic warning message
  • extramsg string additional warning text (optional)
  • fn function deprecated function

Returns:

    function or nil

    a function that warns on its first call, and

    hands off to *fn*; or `nil` if `std._debug.deprecate` is `true`

Usage:

    M.op = DEPRECATED('41', "'std.functional.op'", std.operator)
DEPRECATIONMSG (version, name[, extramsg], level)
Format a deprecation warning message.

Parameters:

  • version string first deprecation release version
  • name string function name for automatic warning message
  • extramsg string additional warning text (optional)
  • level int or false

    call stack level to blame for the warning,

    or `false` to blame nothing

Returns:

    string

    the warning, or an empty string unless

    `std._debug.deprecate` is `nil`

Usage:

    io.stderr:write(DEPRECATIONMSG('42', "multi-argument 'module.fname'", 2))

Functions

say ([n=1], ...)
Print a debugging message to io.stderr. Display arguments passed through std.tostring and separated by tab characters when std._debug hinting is true and n is 1 or less; or std._debug.level is a number greater than or equal to n. If std._debug hinting is false or nil, nothing is written.

Parameters:

  • n integer debugging level, smaller is higher priority (default 1)
  • ... objects to print(as for print)

Usage:

    local _debug = require 'std._debug'
_debug.level = 3
say(2, '_debug status level:', _debug.level)
trace (event)
Trace function calls. Use as debug.sethook(trace, 'cr'), which is done automatically when std._debug.call is set. Based on test/trace-calls.lua from the Lua distribution.

Parameters:

  • event string event causing the call

Usage:

    local _debug = require 'std._debug'
_debug.call = true
local debug = require 'std.debug'
